# Papiers et codes articles TECPAP

Les sacs TECPAP sont fabriqués en papier kraft de deux types : le kraft blanchi (code KB) et le kraft écru, appelé aussi kraft naturel (code KE). Chaque papier est identifié par un code article qui indique le type de papier, le grammage et la laize.

## Papier kraft blanchi (code KB)

Le kraft blanchi est un papier kraft qui a subi un blanchiment : il est de couleur blanche. Dans les codes articles TECPAP, le kraft blanchi est noté KB.

Exemple : KB100L28 désigne un papier kraft blanchi de 100 g/m² et de laize 28 cm.

Autres noms du kraft blanchi :
- en français : blanchi, kraft blanc ;
- en darija : kraft byed, kaghet byed ;
- en arabe : ورق كرافت مبيض، كرافت أبيض.

## Papier kraft écru ou naturel (code KE)

Le kraft écru, appelé aussi kraft naturel, est un papier kraft non blanchi, de couleur brune naturelle. Dans les codes articles TECPAP, le kraft écru est noté KE.

Exemple : KE80L25 désigne un papier kraft écru de 80 g/m² et de laize 25 cm.

Autres noms du kraft écru :
- en français : écru, kraft naturel, kraft brun ;
- en darija : kraft 9ahwi, kaghet 9ahwi ;
- en arabe : ورق كرافت طبيعي، كرافت بني، كرافت غير مبيض.

## Grammage du papier kraft : définition et valeurs standards

Le grammage est la masse d'un mètre carré de papier, exprimée en grammes par mètre carré (g/m²).

Grammages standards des papiers kraft TECPAP : 40, 50, 60, 70, 80, 90, 100, 120 et 140 g/m².

Dans le code article, le grammage suit le type de papier : dans KB100L28, « 100 » signifie 100 g/m². Une commande qui demande un grammage hors de cette liste est signalée à l'équipe commerciale au moment de la validation.

Autres formulations : « ch7al d gram 3ndkom ? », « شحال ديال الغراماج؟ », « ما هي أوزان الورق المتوفرة؟ ».

## Laize du papier kraft : définition et valeurs standards

La laize est la largeur de la bobine de papier utilisée pour fabriquer le sac, exprimée en centimètres (cm).

Laizes standards des papiers kraft TECPAP : 15, 18, 20, 22, 25, 28, 30, 32, 35, 40, 45 et 50 cm.

Dans le code article, la laize suit la lettre L : dans KB100L28, « L28 » signifie une laize de 28 cm. Une commande qui demande une laize hors de cette liste est signalée à l'équipe commerciale au moment de la validation.

Autres formulations : « l3ard dyal lkaghet », « عرض الورق », « عرض البكرة ».

## Format du code article TECPAP

Le code article TECPAP identifie le papier utilisé pour un sac. Il suit le format :

[TYPE][GRAMMAGE]L[LAIZE]

- TYPE : KB (kraft blanchi) ou KE (kraft écru ou naturel) ;
- GRAMMAGE : masse du papier en g/m² ;
- L suivi de la LAIZE : largeur de la bobine de papier en cm.

Les codes internes peuvent comporter un suffixe propre à TECPAP ; il ne change rien pour le client.

Indiquer le code article dans une commande est facultatif : à défaut, le code est déduit du type de papier, du grammage et de la laize indiqués, puis vérifié par l'équipe commerciale.

## Exemple de code article TECPAP : KB100L28

Le code article KB100L28 se lit ainsi :
- KB : papier kraft blanchi ;
- 100 : grammage de 100 g/m² ;
- L28 : laize de 28 cm.

Autre exemple : KE80L25 désigne un papier kraft écru de 80 g/m² et de laize 25 cm.

Autres formulations : « chno kay3ni had l code ? », « شنو كيعني هاد الكود؟ », « ما معنى رمز المنتج؟ ».

## Papier kraft biodégradable et recyclable

Les sacs en papier kraft TECPAP sont 100 % biodégradables et 100 % recyclables.

Autres formulations : « wach les sacs dyalkom kayt-recyclaw ? », « واش الساكات ديالكم كيترسكلاو؟ », « هل الأكياس قابلة لإعادة التدوير وصديقة للبيئة؟ ».
